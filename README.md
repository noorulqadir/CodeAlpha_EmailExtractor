# CodeAlpha_EmailExtractor

A task automation script built for the **CodeAlpha Python Programming Internship (Task 3)**.

It reads a text file, extracts every email address using a regular expression, removes duplicates, and saves the results to a new file.

## Concepts Used
`re`, `os`, file handling

## How to Run
1. Put your text in `input.txt` (a sample is included).
2. Run:
```bash
python email_extractor.py
```
3. The addresses are saved in `emails_found.txt`.
